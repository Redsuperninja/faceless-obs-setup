# Platform logos (not included)

The chat shows a Twitch and a YouTube badge from `twitch.svg` and `youtube.svg` in this folder. They are trademarks, so
they are not shipped here. Download them yourself and save them with those two file names:

| File | Suggested source |
|---|---|
| `twitch.svg` | Wikimedia Commons, "Twitch Glitch Logo Purple" |
| `youtube.svg` | Wikimedia Commons, "YouTube full-color icon (2017)" |

Check each file's license page before you publish a stream that shows them. Without the files the chat still works; the
badges are just blank.
